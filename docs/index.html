HARNESSKIT

워크플로 설계, 서브에이전트 정의, 스킬 연결, 하네스 자동 개선 제안까지.

  1. 하네스, 뭐부터 할지 막막하죠? 한마디면 HarnessKit이 만들어 드립니다.
예시

내 일에 딱 맞는 하네스, 자동으로 만들어 드립니다!

SCAN

만들기 전에, 지금 프로젝트부터 봅니다

설치된 도구와 기존 하네스를 살핀 뒤, 있으면 고쳐 쓰고 없으면 새로 지어요.

  1. 새로 만들기 전에, 깔린 도구와 기존 하네스부터 체크합니다.
  2. 기존 하네스가 있으면 새로 만들지 않고 필요한 단계만 고칩니다.

CATALOG

쓸만한 스킬 57개, 카탈로그에 골라 모아 뒀어요

한국어·문서부터 UI/UX, 개발·리뷰, 테스트·보안, 토큰 절약까지 분야별로 모았어요.

  1. 쓸 만한 스킬, 어디서 찾을지 헤매셨나요?
  2. 직접 써보고 좋았던 도구 57개 카탈로그에 정리해놨어요.

PICK · WEB

목표에 맞게 골라 담고, 웹에서 찾은 스킬도 더해요

목표에 맞는 스킬을 카탈로그에서 골라 담고, 웹에서도 매번 찾아 함께 골라요.

  1. 일에 필요한 역량을 정하고, 카탈로그에서 맞는 스킬을 골라 담습니다.
  2. 카탈로그에만 머물지 않고 웹에서도 더 나은 스킬을 찾아, 괜찮으면 함께 담습니다.
예시

MY CATALOG

SNS에서 본 괜찮은 스킬, 내 카탈로그에 담아 두세요

봐 두고 까먹던 스킬, 이제 실제로 쓸 수 있게 저장해요.

  1. SNS에서 본 좋은 스킬, 나중에 써야지 하고 잊어버리진 않으셨나요?
  2. 링크나 이름만 주면 설치 없이 담아 두고, 하네스 만들 때 후보로 올립니다.

CONFLICT

인기 스킬, 무작정 다 깔면 충돌할 수 있어요

스킬마다 하는 일은 좋아도, 지시가 서로 어긋나면 결과가 흔들려요.

  1. 스킬끼리 지시가 부딪히는지, 설치 전에 찾아 드립니다.
  2. 스킬 우선순위를 정해 충돌을 해결해드립니다.

SECURITY

설치 전에, 충돌·보안 검사부터

스킬은 전역이 아니라, 기본으로 이 프로젝트에만 설치돼요.

  1. 설치 전에 충돌 체크를 하고, NVIDIA SkillSpector로 보안 점검도 합니다.
  2. 통과한 것만 승인받아 설치해 다른 프로젝트의 스킬과 부딪히지 않습니다.
예시

ASSIGN

에이전트마다 맞는 스킬과 모델을 배정해요

있는 스킬은 다시 만들지 않고 연결하고 모델과 추론 강도는 역할에 맞게 나눠요.

  1. 목표에 맞는 에이전트 팀을 짜고, 스킬도 역할에 맞게 배정해 드립니다.
  2. 중요한 에이전트라고 모두 opus로 두지 않고 맡은 일에 맞춰 고릅니다.
예시

BLUEPRINT

계획이 끝나면, 만들기 전에 설계안부터

작업 흐름·에이전트·스킬·지킬 조건을 먼저 보여 드리고 승인받아야 만들어요.

  1. 만든 뒤에 구조를 바꾸느라 다시 고치진 않으셨나요?
  2. 파일을 만들기 전에 설계안을 먼저 보여 드리고 승인받은 뒤 만듭니다.
예시

SHARED

같은 기준 파일을 함께 보며 일해요

슬라이드 작성과 디자인 QA가 같은 DESIGN.md를 봐요.

  1. 디자인 기준 파일을 만들면, 작성하는 쪽과 점검하는 쪽이 같은 파일을 봅니다.
  2. CLAUDE.md에는 호출 조건과 변경 이력만 둡니다.
예시

RUN

이제 한마디면, 팀이 움직입니다

에이전트들이 파일로 결과를 주고받으며 한 팀처럼 일해요.

  1. 팀은 _workspace 폴더에 결과를 남기며 서로 주고받습니다.
  2. 전부 다시 돌릴 필요 없이, 고칠 단계나 에이전트만 다시 실행합니다.
예시

TOKENS

토큰 아끼는 하네스, 만들 때부터 가볍게

받은 파일이 클수록 읽는 양이 늘어요. 그래서 큰 파일은 나눠, 다음 단계가 쓸 것만 넘겨요.

  1. 인계 파일이 크면 실행할 때마다 토큰도 그만큼 들죠?
  2. 큰 파일은 목차와 조각으로 나눠 에이전트가 자기 몫만 읽게 합니다.
예시

SESSION

컨텍스트를 관리해, 토큰을 아껴요

작업 내용을 기록해 새 세션에서도 빠뜨리지 않고 이어 가요.

  1. 컨텍스트가 길어져 토큰이 쌓이면, 새 세션에서 이어 할지 제안합니다.
  2. 할 일과 결정을 md 한 장에 적어 새 세션에서 안정적으로 이어 갑니다.
예시

EVOLVE

하네스 자동 개선, 먼저 알리고 제안해요

실행할 때마다 점검해 회고할 때를 알리고, 바꿀 내용은 승인받은 뒤 반영해요.

  1. 쓰다 보니 하네스가 좀 느리다고 느끼셨나요?
  2. 피드백을 자동으로 감지하고 하네스를 개선합니다.
